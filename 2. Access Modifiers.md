# Access Modifiers

> **One-liner:** Keywords that set the **visibility/reach** of a class member — the toolkit that actually enforces [1. Encapsulation](1.%20Encapsulation.md).

**Trigger phrase:** *"how far can this member be seen? — `private` (class) → `default` (package) → `protected` (package + subclasses) → `public` (everywhere)."*

---

## Core Idea
Access modifiers answer one question: **"who is allowed to touch this member?"** They widen visibility in four steps and are the mechanism behind encapsulation, modularity, and controlled sharing.

## The 4 levels (narrow → wide)
| Modifier | Reach | Use it for |
|---|---|---|
| **`private`** | Same **class** only | Sensitive state (`balance`); force access via getters/setters. Compile-time protection. |
| **`default`** *(no keyword)* | Same **package** | Package-internal helpers — package-level encapsulation. |
| **`protected`** | Same package **+ subclasses** (even in other packages) | Members children should inherit/use. Promotes inheritance. |
| **`public`** | **Everywhere** | APIs and universally-needed methods/attributes. |

## Visibility Matrix (memorize this)
| Modifier | Class | Package | Subclass | World |
|---|:---:|:---:|:---:|:---:|
| **public**    | ✔️ | ✔️ | ✔️ | ✔️ |
| **protected** | ✔️ | ✔️ | ✔️ | ❌ |
| **default**   | ✔️ | ✔️ | ❌ | ❌ |
| **private**   | ✔️ | ❌ | ❌ | ❌ |

> Pattern: each step down **removes one column from the right** (World → Subclass → Package). Only `protected` breaks the strict-staircase — it adds *Subclass* back on top of package access.

## Minimal Examples
```java
class Account {
    public String id;        // visible everywhere
    private double balance;   // only inside Account → use getBalance()
    protected String type;    // Account + subclasses + same package
    void log() { }            // default → same package only
}
```
```java
// private blocks outside access:
System.out.println(acnt.balance);      // ❌ compile error
System.out.println(acnt.getBalance()); // ✔️ controlled access

// protected flows into subclasses:
class Car extends Vehicle { Car(){ this.type = "Car"; } } // ✔️
```

## Key Takeaways
1. **Default has no keyword** — leaving it blank = package-private, *not* public.
2. **`protected` = package + subclasses**, a strict superset of `default`.
3. **`private` is the encapsulation workhorse** — hide state, expose validated methods.
4. Order to recall: **private ⊂ default ⊂ protected ⊂ public** (each strictly wider).

## Pitfalls
- **`protected` is *not* "subclass only."** It also grants the whole package access — wider than people assume.
- **Default ≠ public.** Forgetting a modifier silently restricts to the package; a member you expected to be visible elsewhere won't be.
- **Java only:** these reaches are package-based. In C++ there's no `default`/package level and `protected`/`private` don't involve packages — don't carry the matrix over verbatim.
